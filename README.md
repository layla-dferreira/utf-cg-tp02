## 🌊 Paraíso One Piece

### 1. 🚀 O Projeto

O projeto consiste num diorama 3D interativo inspirado no 
universo de One Piece, renderizado em WebGL 2.0. O cenário 
destaca o icónico navio Going Merry a navegar sobre um 
oceano circular com animação de ondas, contido sob uma 
redoma de vidro translúcida. O ambiente ganha vida através 
de um sistema de iluminação dinâmica (modelo de Phong), 
nuvens estilizadas em low-poly com volume calculado no shader, 
e uma gaivota construída hierarquicamente que bate as asas enquanto sobrevoa o mar.

Controles

|Câmera 1 | `1` |

| Tira/Coloca iluminação Phong | `L` |
| Pausa/Play na musica | `M` |
| Mover a câmera na 2 e 3 | clique esquerdo do mouse |
| Aumentar/Diminuir | scroll do mouse |

### 4. ⭐ Itens opcionais implementados

- Modelos tridimensionais: em vez de usar os sólidos próprios ou da TWGL.js,
crie ou use modelos tridimensionais de terceiros e carregue-os no seu programa.
Um formato simples é o .obj (mas ele não suporta animação). Tem também o formato
glTF (mais complexo mas suporta animação)
- Vários tipos de objetos: em vez de compor o cenário com apenas 03 tipos de objetos,
tenha uns 07 tipos diferentes para dar variedade
- Líquido: tenha uma região aquática como um lago, poça d'água, mar ou rio. Uma ideia
para que um sólido pareça água é que ele (a) tenha certa transparência, (b) tenha uma
textura com suas coordenadas animadas e (c-para oceano ou rio agitado) desloque
verticalmente os vértices da superfície ao longo do tempo para criar ondas
- Câmera de navegação livre com WASD para voar e mouse para mudar direção
- Música, efeitos sonoros e/ou som ambiente: inclua música de fundo, sons ambiente e efeitos sonoros
(este último, caso haja algum tipo de interação)

### 6. 📌 Observações

O projeto foi desenvolvido como atividade acadêmica, utilizando WebGL
2.0 para renderização dos elementos do projeto e JavaScript para
implementar a lógica de câmeras, movimentação, carregamento dos 
objetos 3D e demais mecânicas.
